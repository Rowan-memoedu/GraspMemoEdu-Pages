GraspMemoEdu打开网页版

把学习放到桌面。

在 iPhone、安卓手机或 Windows 上安装 GraspMemoEdu。阅读、练习与复习，继续使用同一账号的学习进度。

进入学习

当前已在应用窗口中打开。

iPhone / iPad安卓Windows

iPhone / iPad

用 Safari 添加到主屏幕。

  1. 在 Safari 中打开本页。如果在微信等应用内，请复制链接到 Safari。
  2. 点击“分享”，选择“添加到主屏幕”。若显示“作为网页 App 打开”，保持开启。
  3. 点击“添加”，从主屏幕上的 GraspMemoEdu 图标打开并登录。

无需 App Store、TestFlight、描述文件或 Apple 开发者会员。

安卓

使用最新版 Chrome 或 Edge 打开。

  1. 在浏览器中打开本页，点击上方出现的“安装 GraspMemoEdu”。
  2. 没有安装按钮时，打开浏览器菜单，选择“安装应用”或“添加到主屏幕”。
  3. 按系统提示确认，从新增图标打开并登录。

部分浏览器和手机只会添加快捷方式。是否生成独立应用入口，以手机的实际安装结果为准。

Windows

使用 Microsoft Edge 或 Google Chrome。

  1. 在 Edge 或 Chrome 中打开本页。
  2. 点击地址栏的安装图标；也可在浏览器菜单中选择“应用 → 将此站点作为应用安装”或“安装 GraspMemoEdu”。
  3. 确认安装后，从开始菜单或桌面图标打开；可按需固定到任务栏。

以独立窗口运行，无需下载 EXE。菜单名称可能随浏览器版本略有不同。

安装后怎么使用

需要联网。使用同一账号登录后，继续读取云端课程和学习进度；首次从应用打开时可能需要重新登录，游客进度不会自动跨设备合并。

网页更新无需重新安装。正在答题时不会因安装组件更新而自动刷新；完成当前操作后重新打开即可读取新版页面。
